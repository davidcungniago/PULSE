```sh

docker compose --env-file /opt/pulse/.env -f deploy/compose.yml -p pulse-live ps
```

`--env-file` wajib karena Compose tidak otomatis membaca `/opt/pulse/.env` saat file Compose berada di `deploy/`. ## P10 — issue pascadeploy

Minimal 10 issue GitHub harus berasal dari bug yang dapat direproduksi pada aplikasi live. Tiap issue memerlukan versi/URL, langkah reproduksi, hasil yang diharapkan dan terjadi, bukti, commit perbaikan, serta retest sebelum ditutup. Belum ada issue GitHub yang dibuat atau dinyatakan solved. Konektor GitHub belum tersedia bagi agen (`installed: false` pada pemeriksaan 16 November 2026).

Audit live menemukan tujuh masalah yang berbeda:

1. Navigasi `push` ke dashboard/hasil pemindaian tidak mengubah URL dari `#/projects`; refresh kembali ke daftar proyek. Diperbaiki melalui `GoRouter.optionURLReflectsImperativeAPIs = true`, diuji dengan `test/routes/app_router_test.dart`, dibangun ulang, dan dipasang di VPS. Retest browser membuka proyek lalu hasil pemindaian menunjukkan URL detail yang benar; pemuatan ulang URL hasil pemindaian mempertahankan layar tersebut. [Bukti snapshot setelah perbaikan](screenshots/p10-navigation-deep-link-fixed.yml).
2. Rute yang tidak dikenal menampilkan `Page Not Found` dan `Home` dalam bahasa Inggris; tombol `Home` tidak keluar dari halaman error. [Bukti screenshot](screenshots/p10-unknown-route-english.png). Belum diperbaiki.
3. Tombol ikon profil pada daftar proyek dan tombol ikon notifikasi pada dashboard tidak memiliki nama aksesibilitas. [Bukti snapshot semantik](screenshots/p10-unlabeled-controls.yml). Belum diperbaiki.
4. Membuka `/pulse/` tanpa sesi memicu dua `GET /api/projects` yang berakhir 401 sebelum layar login muncul. Membuka `#/login` langsung tidak memicu request tersebut. Logout juga memicu request proyek/dashboard yang berakhir 401. [Bukti daftar request](screenshots/p10-unauth-project-requests.txt). Belum diperbaiki.
5. Radar membagikan catatan lokal antar akun pada browser yang sama: akun A menambahkan `dart-lang/sdk` dengan catatan “Catatan akun audit A”, lalu akun B yang baru didaftarkan melihat catatan itu. [Bukti snapshot akun B](screenshots/p10-watchlist-cross-account.yml). Perbaikan lokal memakai koleksi `SharedPreferences` per ID pengguna dan invalidasi provider pada pergantian sesi; unit test dua akun, data lama tanpa pemilik, serta sesi kosong lulus. Build web berhasil, tetapi retest live menunggu pembaruan sesi AWS.
6. Radar menerima `https://github.com/expressjs/express.git/` sebagai item baru ketika `https://github.com/expressjs/express` sudah ada, walaupun dokumentasi P5 menyatakan keduanya setara. [Bukti dua entri di Radar](screenshots/p10-watchlist-duplicate-url.yml). Belum diperbaiki.
7. Kontrol bawaan yang dibaca pembaca layar masih berbahasa Inggris: tombol kembali bernama `Back` dan penutup modal bernama `Dismiss`, sedangkan seluruh teks aplikasi seharusnya berbahasa Indonesia. [Bukti label modal](screenshots/p10-untranslated-system-controls.yml). Belum diperbaiki.

Ketujuh temuan belum menjadi issue GitHub; masalah yang sudah diperbaiki pun belum boleh ditandai solved pada reviewer sebelum issue dibuat, perubahan di-commit/push oleh pemilik, dan issue ditutup setelah retest.

Temuan nyata selama deploy: (1) perintah Compose tanpa `--env-file` gagal menemukan variabel; instruksi sudah dikoreksi; (2) paket Amazon Linux tidak menyediakan `docker-compose-plugin` dan Compose v5 gagal build tanpa Buildx; plugin resmi dipasang dan build berhasil; (3) build web lama mengunci API ke localhost; `api_endpoint.dart` memakai origin halaman dan uji auth live berhasil. Temuan instalasi server ini tidak otomatis dihitung sebagai sepuluh bug aplikasi pascadeploy.
